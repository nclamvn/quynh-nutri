`/ops/activation` at 50 ms p50, 3.57 s p90, and 3.7 s p95 across 58 hot

authorization, Neon reads, aggregation, and the complete report render before

## TASK

Reduce first-byte blocking without changing `ke031-v1`, privacy suppression,
authorization, Neon schema, or aggregate definitions.

Keep the initial operator authorization before streaming so denied users retain
a real 404 response. Move search-parameter resolution, repository authorization,
Neon reads, aggregation, and report rendering into a nested async Server
Component behind an explicit Suspense fallback.

The fallback must:

- contain no operator or household data;
- reserve useful layout space;
- remain responsive at 375 px;
- respect reduced-motion preferences;
- use one-line Vietnamese interface copy where space permits.

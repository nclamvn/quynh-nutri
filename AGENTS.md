# Typography rules

- Never use an em dash in product copy. Use an en dash (`–`) instead.
- Keep sentence-style interface copy on one line at desktop widths when the container has room.
- On narrow screens, wrap by meaningful phrases and never leave a single orphan word on its own line unless the content makes that unavoidable.
